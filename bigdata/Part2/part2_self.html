문제 1 Cars93

Wheelbase 컬럼의 평균에서 표준편차의 1.5배, 2배, 2.5배를 더하거나 뺀 구간 내 데이터들의 평균을 각각 구한 후, 원래 데이터 평균에서 뺀 차이들의 합을 출력하여라. (단, 소수점 다섯째 자리에서 반올림하여 표현할 것)
import pandas as pd exam1 = pd.read_csv('data/연습문제/Cars93.csv') wb = exam1['Wheelbase'] wb_mean = wb.mean() wb_std = wb.std() lower1 = wb_mean - wb_std * 1.5 upper1 = wb_mean + wb_std * 1.5 case1 = wb_mean - wb[(wb > lower1) & (wb < upper1)].mean() lower2 = wb_mean - wb_std * 2 upper2 = wb_mean + wb_std * 2 case2 = wb_mean - wb[(wb > lower2) & (wb < upper2)].mean() lower3 = wb_mean - wb_std * 2.5 upper3 = wb_mean + wb_std * 2.5 case3 = wb_mean - wb[(wb > lower3) & (wb < upper3)].mean() result = case1 + case2 + case3 print(round(result, 4))

문제 2 Cars93

Length 컬럼에 순위를 부여한 후, 1위~30위 값들의 표준편차를 구하여라. (단, 동점은 평균 순위로 산정하며 최솟값을 1위로 함, 소수점 셋째 자리까지 반올림)
import pandas as pd exam2 = pd.read_csv('data/연습문제/Cars93.csv') rank = exam2['Length'].rank(method='average') rank30 = exam2['Length'][rank <= 30] std = rank30.std() print(round(std, 3))

문제 3 Cars93

Max_Price 컬럼과 Min_Price 컬럼을 각각 정렬한 후 레코드별로 두 값의 차이를 산출하고 표준편차를 구하여라. (단, Max_Price 내림차순 / Min_Price 오름차순, 소수점 넷째 자리에서 반올림)
import pandas as pd exam3 = pd.read_csv('data/연습문제/Cars93.csv') maxp = exam3['Max_Price'].sort_values(ascending=False, ignore_index=True) minp = exam3['Min_Price'].sort_values(ascending=True, ignore_index=True) diff = maxp - minp std = diff.std() print(round(std, 3))

문제 4 Cars93

Weight 컬럼을 Min-Max 정규화로 변환한 후, 0.5 미만 값들의 분산과 0.5 초과 값들의 분산의 차이를 구하여라. (단, 큰 값에서 작은 값을 빼서 구하며, 소수점 넷째 자리에서 반올림)
import pandas as pd exam4 = pd.read_csv('data/연습문제/Cars93.csv') weight = exam4['Weight'] mms = (weight - weight.min()) / (weight.max() - weight.min()) cond1 = mms[mms < 0.5].var() cond2 = mms[mms > 0.5].var() diff = abs(cond1 - cond2) print(round(diff, 3))
